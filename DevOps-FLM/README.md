# End-to-End CI/CD Pipeline Using Jenkins & Docker Swarm

## Tools Used
- Jenkins
- Maven
- SonarQube
- Nexus
- Docker
- Docker Swarm
- Trivy
- GitHub

## Features
- CI/CD Automation
- Docker Image Build & Push
- Vulnerability Scanning
- Multi-node Swarm Deployment
- Overlay Networking
- Secrets Management
- High Availability

## Pipeline Flow
GitHub → Jenkins → SonarQube → Maven Build → Nexus → Docker Build → Trivy Scan → Docker Hub → Docker Swarm Deployment
